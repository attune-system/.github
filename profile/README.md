# Attune

**Open-source, event-driven automation and orchestration, built in Rust.**

Attune connects signals from your systems to reliable, reviewable action. Sensors
record events, rules decide what runs, and executions preserve the path from
input to result. Workflows, queues, approvals, and artifacts use the same model.

Run Attune on infrastructure you control with no license key or paid edition.
The project is under active development and is not yet production-ready.

## Start here

- [attune](https://github.com/attune-system/attune) contains the Rust services,
  web client, CLI, MCP server, and core pack.
- [attune-docs-site](https://github.com/attune-system/attune-docs-site) contains
  the user and operator documentation.
- [index](https://github.com/attune-system/index) is the Attune Standard Pack
  Index.
- [agent-skills](https://github.com/attune-system/agent-skills) contains skills
  for agents that design, write, test, and translate Attune packs.
- [attune-charts](https://github.com/attune-system/attune-charts) contains Helm
  charts for Attune and its public sites.

## Build with Attune

Write actions and managed sensors with the
[Python](https://github.com/attune-system/python-attune-sdk),
[TypeScript](https://github.com/attune-system/js-attune-sdk), or
[Java](https://github.com/attune-system/java-attune-sdk) SDK. Package actions,
sensors, triggers, rules, workflows, and runtime definitions together, then
publish them through the Standard Pack Index.

Read the [pack development guide](https://docs.attunedev.org/pack-development/overview/)
to build your first pack.
